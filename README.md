## 🔧 1. Préparation technique

Avant de commencer, assurez-vous d’avoir installé un **serveur local** compatible avec PHP. Selon votre système d’exploitation, vous pouvez utiliser :

- **WAMP** (Windows)  
- **MAMP** (Mac)  
- **LAMP** (Linux)  

Le serveur doit impérativement inclure **Apache**. Une fois le serveur installé et configuré :

1. Transférez tous les fichiers du jeu dans le dossier `www` (ou équivalent) de votre serveur.
2. Lancez votre serveur local.
3. Ouvrez votre navigateur et accédez au **site vitrine** du jeu.

## 🧩 3. Les étapes du jeu

L’Escape Game est composé de **5 épreuves**, chacune sollicitant vos compétences en **logique**, **observation** et **pensée critique** :

- **Étape 1 : Quiz**  
  Répondez correctement à des questions pour obtenir le mot de passe d’accès à l’étape suivante.

- **Étape 2 : Code Morse**  
  Décryptez un message codé en Morse. Le mot trouvé est essentiel pour progresser.

- **Étape 3 : Chiffrement César**  
  Utilisez la bonne clé de décalage pour déchiffrer un texte codé et révéler un mot de passe.

- **Étape 4 : Photos de postes de travail**  
  Analysez des photos de postes informatiques. Des indices visuels y sont dissimulés : à vous de les repérer.

- **Étape 5 : Identification du suspect**  
  Examinez les **CV et indices** fournis pour trouver qui est à l’origine de l’infection numérique.

---

## 🔍 4. Résolution finale

Une fois le suspect identifié, accédez à la **page du virus**. Saisissez :

- Le **nom et prénom** du coupable
- Le **mot de passe clé** obtenu lors des épreuves

Si toutes les informations sont correctes, le virus sera neutralisé : **mission accomplie** !
